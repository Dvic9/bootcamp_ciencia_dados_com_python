🎓 Projetos do Santander Bootcamp 2025

Estes projetos foram desenvolvidos como desafios práticos durante o bootcamp, onde apliquei conceitos de Python para resolver problemas reais de negócio.

1. ☁️ Redução de Custos em Farmácias com AWS

Focado em arquitetura de nuvem e viabilidade financeira para a Abstergo Industries.

O que faz: Planejamento de migração de ambiente On-premise para AWS (EC2, S3, RDS).

Destaque: Redução projetada de 42% nos custos operacionais em 3 anos.

Arquivos: Relatório de implementação, cronograma de migração e comparativo de custos.

2. 📊 Dashboard de Assinaturas PlayStation Plus

Análise de dados focada em retenção e faturamento (KPIs de negócio).

O que faz: Processamento de base de dados de assinantes (Essential, Extra, Deluxe) com lógica de cross-selling (Ubisoft+ e Fortnite).

Destaque: Dashboard autoral criado do zero, fugindo do tema padrão de bootcamps para simular um cenário real de mercado.

Arquivos: Base de dados, cálculos dinâmicos e ativos visuais.

3. 🎮 Api Playstation & Pipeline ETL (IA)

Integração de sistemas e Inteligência Artificial generativa.

O que faz: Um pipeline completo que extrai dados de jogadores via API (FastAPI), utiliza o Google Gemini AI para gerar recomendações personalizadas e carrega os dados de volta.

Destaque: Adaptação do desafio de ETL para o ecossistema PlayStation, utilizando IA para transformar dados brutos em mensagens de marketing segmentadas.

Arquivos: main.py (API), pipeline_psn_etl.ipynb e requirements.txt.
